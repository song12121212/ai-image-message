# AI Image Message

문자 내용과 현재 날씨에 어울리는 이미지를 생성형 AI로 만들어, 뿌리오 API로 포토문자를 보내는 웹 서비스입니다.

- **5인 팀 프로젝트** · 프리캡스톤 디자인 (2024)
- 이 저장소는 포트폴리오 공개용 사본입니다. 키와 개인정보를 제거했고 원본 커밋 기록은 포함하지 않았습니다.

## 배경

생성형 AI로 광고 이미지를 만들면 알 수 없는 문자와 숫자가 섞이는 문제가 있었습니다. 문자 내용을 LLM으로 이미지용 프롬프트로 바꾸고, 날씨·계절에 맞는 스타일링 이미지를 만들도록 구성했습니다.

## 동작 흐름

1. 사용자가 문자 내용을 입력합니다.
2. 기상청 API로 현재 날씨를 가져옵니다.
3. LLM이 문자 내용과 날씨를 이미지 프롬프트로 바꿉니다.
4. DALL-E가 만든 이미지 중 하나를 선택합니다.
5. 이미지 용량을 줄인 뒤 뿌리오 API로 전송합니다.

## 주요 기능

- 날씨 위젯과 날씨 기반 이미지 생성
- 메시지 작성, 미리보기, 발송 내역
- 주소록과 연락처 관리
- 회원가입, 로그인

## 기술

JavaScript, Node.js, Express, SQLite, Bootstrap, OpenAI API, 기상청 API, 뿌리오 API

## 내 역할

- 메시지 작성·주소록 화면 개발, 날씨 위젯 오류 수정
- DALL-E 3 연동, 이미지 용량 변환, 문자 전송 오류 수정

## 실행 방법

```bash
npm install
cd backend
npm install
cp touch.env.example touch.env
node db_init.js
node server.js
```

`touch.env`에 각 서비스의 키를 넣고 http://localhost:5000 으로 접속합니다. 수업용 프로젝트이며 공개 서버 배포를 위한 보안 처리는 되어 있지 않습니다.
